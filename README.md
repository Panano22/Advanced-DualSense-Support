# Adaptive DualSense Triggers for Euro Truck Simulator 2
**Feel the Road. Feel the Truck. Fully Enhanced DualSense Experience.**  

This mod adds realistic **Adaptive Trigger** effects and improved haptics for the **DualSense** controller in Euro Truck Simulator 2.  
Throttle resistance, brake pressure, road vibration, damage feedback — everything you can *feel* now.

---

## ✨ Features
- Adaptive triggers for throttle and brake with realistic physics
- Haptic vibration for:
  - Gear shifting
  - Emergency braking
  - Engine stall & collisions
- Works with vanilla and many modded trucks

---

## 🔧 Requirements
This mod requires **DualSenseX**:

| DSX Version | Status | Notes |
|------------|--------|------|
| **Steam version** | ✔ Recommended | Full features + updates |
| **Free GitHub build** | ✔ Supported | Limited features, not tested by me |

---

## 📥 Installation
1. Extract all mod files directly into your  
   **Euro Truck Simulator 2 installation directory**
2. Launch **DualSenseX**
3. Open Settings in DSX → Networking → enable Incoming UDP Port 6969
4. Launch game
5. When it asks about SDK - press OK
6. You are ready to ride)

📌 *Make sure the controller is connected via USB for full effects.*


## ❗ Notes
